Preguntas Frecuentes

¿Cuál es la señal de socorro SOS en código Morse?
La señal es '... --- ...' (tres puntos, tres rayas, tres puntos). Se transmite de forma continua sin espacios entre las letras para indicar una emergencia inmediata.
¿Por qué no funciona el flash en mi navegador?
La activación del flash (Torch) requiere que el navegador tenga permisos de cámara. Algunos navegadores móviles o versiones antiguas de escritorio no soportan esta API por motivos de privacidad.
¿Es visible la señal de SOS de la pantalla?
Sí, en condiciones de oscuridad absoluta, el brillo máximo de una pantalla blanca parpadeando en Morse puede verse a varios cientos de metros de distancia, siendo una alternativa útil si el flash falla.
¿Qué es el código Morse internacional?
Es un sistema de comunicación que utiliza secuencias de señales cortas (puntos) y largas (rayas) para representar letras y números, estandarizado por la UIT para comunicaciones de radio y señales ópticas.

El Lenguaje de la Luz

Esta herramienta convierte tu dispositivo en una baliza de señalización óptica capaz de transmitir mensajes visibles a kilómetros de distancia. Utilizando el estándar internacional del Código Morse, permite la comunicación silenciosa o de emergencia mediante pulsos de luz (linterna y pantalla).

Un Estándar Universal

Desarrollado en 1830 por Samuel Morse, este sistema binario de puntos y rayas revolucionó las telecomunicaciones. Su simplicidad lo hace extremadamente robusto: puede transmitirse por sonido, radio, electricidad o, como en este caso, luz, siendo legible incluso con interferencias severas.

Modo SOS de Emergencia

El botón de "SOS Loop" transmite continuamente la secuencia ··· --- ···. Esta señal es reconocida mundialmente como petición de auxilio y, gracias al alto contraste del flash LED, es visible a gran distancia incluso a plena luz del día en ciertas condiciones.

Estándar ITU-R M.1677-1

Esta utilidad respeta estrictamente los tiempos reglamentarios del código Morse internacional:

  • 1 punto = 1 unidad de tiempo
  • 1 raya = 3 unidades de tiempo
  • Espacio entre partes = 1 unidad
  • Espacio entre letras = 3 unidades

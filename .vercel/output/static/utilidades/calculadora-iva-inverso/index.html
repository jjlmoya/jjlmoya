Preguntas Frecuentes

¿Qué es el IVA Inverso o desglosar el IVA?
Es el proceso de calcular la base imponible a partir de un precio total que ya incluye el impuesto. Es fundamental para autónomos que necesitan emitir facturas a partir de un precio final acordado.
¿Cómo se calcula manualmente el IVA inverso?
Para un IVA del 21%, debes dividir el importe total entre 1.21. El resultado es la base imponible. La diferencia entre el total y la base es la cuota de IVA.
¿Qué tipos de IVA existen en España?
Existen tres tipos: el General (21%), el Reducido (10% para alimentación, salud, vivienda) y el Superreducido (4% para libros, periódicos, pan, leche).
¿Cuándo es obligatorio desglosar el IVA?
Siempre que emitas una factura profesional o simplificada. Es obligatorio indicar por separado la base imponible, el tipo impositivo aplicado y la cuota total de IVA.

El Problema de Desglosar el IVA Inverso

Para muchos autónomos y pymes, calcular la base imponible a partir de un precio total sigue siendo un quebradero de cabeza. El error más común es pensar que para quitar un 21% de IVA, simplemente restas el 21% al total. ¡Esto es incorrecto! Hacerlo así te hará perder dinero en cada trimestre.

La Matemática Explicada

El Error Común (No hagas esto)

100€ - 21% = 79€

Si luego sumas el 21% a 79€, obtienes 95,59€, ¡no 100€!

CORRECTO

La Fórmula Real

Base = Total / (1 + Tasa)

100 / 1.21 = 82,64€

El IVA se aplica sobre la base. Por tanto, el precio final es el 121% de la base (si el IVA es 21%).

Para volver atrás, no restamos; dividimos. Al dividir por 1.21, estamos preguntando: "¿Qué número, multiplicado por 1.21, me da 100?". Esta es la única forma de obtener el desglose exacto para tu modelo 303.

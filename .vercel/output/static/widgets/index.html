¿Qué es oEmbed?

Es la tecnología "mágica" que usa WordPress, Twitter o Discord. Solo pegas un enlace simple y se convierte automáticamente en una tarjeta visual.

Más fácil Mejor para autores

¿Qué es iFrame?

Es una "ventana" hacia otra web. Es código HTML puro, universal y funciona en cualquier sitio web del mundo (Wix, Shopify, HTML estático...).

Universal Técnico

¿Dónde puedo usar estos widgets?

WordPress

100% Compatible. Usa el enlace oEmbed (opción A) o el iFrame (opción B).

Wix / Shopify

Busca el bloque "Incrustar sitio" o "HTML". Usa el enlace con ?widget=true.

Squarespace

Añade un "Bloque de código" y pega el código iFrame completo.

Desarrollo a Medida

Funciona en todas partes. Solo copia y pega el código iFrame.

¿Usas WordPress? Guía de Instalación

A
Opción Básica (Sin Plugin)

Copia el "Enlace oEmbed" y pégalo directamente en tu editor de WordPress. Se convertirá en una tarjeta automáticamente.

¿Se ve cortado?
WordPress bloquea el "auto-ajuste" de altura por seguridad. Si el widget se ve incompleto, prueba la Opción B.
Solución Manual: Puedes añadir una Clase CSS o estilos personalizados desde la pestaña "Avanzado" del bloque para ajustar la altura.
B
Opción Pro (Recomendada)

Para que la altura se ajuste mágicamente y nunca se corte:

  1. Instala el plugin gratuito Iframely desde el repositorio.
  2. Actívalo (no requiere configuración).
  3. Pega el enlace de nuevo. ¡Ahora se ajustará perfecto! ✨
